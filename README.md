# Calendar App

Một ứng dụng lịch (Calendar) mã nguồn mở, được thiết kế và tối ưu đặc biệt cho các hệ máy chơi game cầm tay (như Trimui Brick Pro, TrimUI Smart Pro).

## 🌟 Tính năng chính
- Xem lịch theo tháng rõ ràng, trực quan.
- Hỗ trợ xem cả Lịch Dương (Solar) và Âm Lịch (Lunar).
- Đánh dấu và làm nổi bật ngày hiện tại.
- Giao diện giấy cũ cổ điển (Warm Paper Vintage).
- Tương thích tốt với điều hướng bằng gamepad (joystick) trên máy chơi game retro.
