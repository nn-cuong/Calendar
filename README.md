# Calendar App

Một ứng dụng lịch (Calendar) mã nguồn mở, được thiết kế và tối ưu đặc biệt cho các hệ máy chơi game cầm tay (như Trimui Brick Pro, TrimUI Smart Pro).

## 🌟 Tính năng chính
- Xem lịch theo tháng rõ ràng, trực quan.
- Hỗ trợ xem cả Lịch Dương (Solar) và Âm Lịch (Lunar).
- Đánh dấu và làm nổi bật ngày hiện tại.
- Giao diện giấy cũ cổ điển (Warm Paper Vintage).
- Tương thích tốt với điều hướng bằng gamepad (joystick) trên máy chơi game retro.

## ⚙️ Hướng dẫn cài đặt
Để cài đặt ứng dụng lên máy Trimui của bạn, chỉ cần làm theo các bước đơn giản sau:
1. Bấm vào nút `<> Code` màu xanh lá ở trên Github, sau đó chọn **Download ZIP** để tải mã nguồn về máy tính.
2. Giải nén file ZIP vừa tải ra, đảm bảo thư mục giải nén được đặt tên là `Calendar`.
3. **Copy toàn bộ thư mục `Calendar` đó và dán vào thư mục `Apps` nằm trên thẻ nhớ (SD Card) của máy.**
4. Lắp thẻ nhớ vào máy Trimui, ứng dụng sẽ tự động xuất hiện trong giao diện menu Apps.
